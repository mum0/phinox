## 3. Data Model Map

```
accounts.User (UUID)────────┐
  │                          │
  ├─< accounts.Address       │  (governorate = TextChoices enum, 27 values)
  │                          │
  ├─< cart.Cart ─< cart.CartItem >─ catalog.ProductVariant (UUID)
  │       │                        │
  │       │  (user XOR session_key │  (unique per product × size × color)
  │       │   check constraint)    │
  │       │                        ├─< catalog.ProductImage (1 primary per product)
  │       │                        ├─> catalog.Size
  │       │                        ├─> catalog.Color
  │       │                        └─> catalog.Product (UUID)
  │       │                              │
  │       │                              ├─> catalog.Category (self-ref tree)
  │       │                              └─< catalog.Collection (M2M)
  │       │
  ├─< orders.Order ─< orders.OrderItem >─ catalog.ProductVariant (SET_NULL)
  │       │  (denormalized shipping      (denormalized product/variant snapshot:
  │       │   + money snapshot)           name, sku, size, color, price, qty, line_total)
  │       │
  │       ├─> accounts.Address (SET_NULL, convenience link)
  │       ├─> promotions.Coupon (SET_NULL)
  │       └─< payments.Payment
  │              (Paymob fields + provider-agnostic + raw_webhook_payload JSON)
  │
  ├─< wishlist.WishlistItem >─ catalog.Product (CASCADE)
  │                          └─> catalog.ProductVariant (optional, CASCADE)
  │
  └─< reviews.Review >─ catalog.Product (CASCADE)
         (rating 1-5, unique per user×product, is_approved moderation gate)

inventory.Warehouse ─< inventory.Inventory >─ catalog.ProductVariant
                        (reserved ≤ on_hand check, low_stock_threshold)
```

### Primary-key strategy
- **UUID** on externally-referenced entities: `User`, `Address`, `Product`, `ProductVariant`, `Cart`, `WishlistItem`, `Order`, `Payment`, `Coupon`, `Review`.
- **BigAutoField** on internal/operational tables: `Category`, `Collection`, `Size`, `Color`, `ProductImage`, `Warehouse`, `Inventory`, `CartItem`, `OrderItem`.

### Denormalization (deliberate, documented exceptions to 3NF)
1. **`orders.Order`** stores a FK to `Address` **plus** snapshot fields (`shipping_recipient_name`, `shipping_phone_number`, `shipping_governorate`, `shipping_city`, `shipping_street_address`). An order must stay historically accurate even if the customer edits/deletes their address book.
2. **`orders.OrderItem`** stores a FK to `ProductVariant` **plus** snapshot fields (`product_name`, `variant_sku`, `size_label`, `color_name`, `unit_price`). An order must stay accurate even if the catalog changes a product's name/price/variant afterward.
3. **`cart.CartItem.unit_price_snapshot`** freezes the price at add-to-cart time, so later catalog price changes don't retroactively alter an open cart.

> ⚠️ **Do NOT "fix" these by normalizing them.** They are documented in the module docstrings of `apps/orders/models.py` and `apps/cart/models.py`. Removing them would silently rewrite order/cart history on legitimate edits.

## 6. Design Token System

Two families shipped side-by-side pending **open question #5** (which is canonical). Both are in `static/css/tokens.css` and each base template embeds its own Tailwind CDN config block (pixel-fidelity with the Stitch source).

| Token | Family A (Checkout) | Family B (Editorial: 404/Contact) |
|---|---|---|
| `margin-mobile` | 16px | 20px |
| `margin-desktop` | 40px | 64px |
| `radius` | 0px | 0px (Contact) — 404 had 0.25/0.5/0.75rem (treated as export bug, see open Q#6) |
| `touch-target-min` | 48px | undefined in source → defaulted to 48px (open Q#7) |
| Body font | — | Hanken Grotesk |
| Display font | Archivo Narrow | Archivo Narrow |
| Mono font | JetBrains Mono | JetBrains Mono |
| `fire-orange` | `#E85D04` (named) | `#E85D04` (hardcoded inline) |

**Shared palette** (identical across all pages): surface `#121414`, on-surface `#e3e2e2`, surface-bright `#38393a`, outline `#8e9192`, tertiary `#ffb596`.

> ⚠️ **Brand law**: zero border-radius. Ever. On inputs, buttons, cards, images — everything. Do not add `rounded-*` classes.

## 9. Tech Debt Register (acknowledged, not yet paid)

1. **Hand-authored migrations** — `migrations/0001_initial.py` files were hand-written (sandbox had no Django). `python manage.py makemigrations --check --dry-run` must be run in a real env to verify; if drift, treat `models.py` as source of truth.
2. **Tailwind CDN** — every base template loads `cdn.tailwindcss.com`. Production build (`package.json` → `build:css`) exists but is not wired into templates.
3. **No tests** — `pytest` + `pytest-django` + `factory-boy` are in `requirements/dev.txt` but no test files exist yet.
4. **No serializers / viewsets / API URLs** — `apps/api/` is an empty scaffold.
5. **No auth views/forms** — `AUTH_USER_MODEL` is set, `phone_number` field exists, but no login/register/OTP flow.
6. **`DEFAULT_FILE_STORAGE` typo risk** — `prod.py` uses the Django < 4.2 `DEFAULT_FILE_STORAGE` setting. Django 5.0 wants `STORAGES["default"]["BACKEND"]`. Verify before deploy.
